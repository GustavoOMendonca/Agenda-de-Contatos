# Agenda de Contatos

Sistema simples de agenda de contatos desenvolvido em Java com foco em prática de lógica de programação, manipulação de arrays e organização de código.

---

## Objetivo

Este projeto foi desenvolvido com o objetivo de praticar:

- Lógica de programação
- Estruturas de repetição
- Métodos
- Arrays
- Organização de código em Java
- Entrada e saída de dados no terminal

---

## Funcionalidades

- Adicionar contatos
- Listar contatos cadastrados
- Buscar contatos
- Remover contatos
- Atualizar informações de contatos

---

## Tecnologias Utilizadas

- Java
- IntelliJ IDEA
- Git
- GitHub
